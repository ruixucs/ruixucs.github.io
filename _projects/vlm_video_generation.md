## Project Overview

During my AI Research Internship at Peking University, I developed a **VLM** framework for stylized video generation. This project addresses two key challenges in Image-to-Video (I2V) models: **limited semantic understanding** and **conditional image leakage**.

### Key Contributions

1. **VLM Integration**: Incorporated a frozen Qwen2.5-VL into the I2V pipeline to enhance semantic understanding without retraining
2. **Stylized Dataset**: Built a 600K+ image dataset across 13 artistic styles

The architecture consists of three main components:

| Component | Description |
|-----------|-------------|
| **Causal VAE** | Bidirectional mapping between pixel and latent space with 4x temporal / 8x spatial downsampling |
| **Multimodal Encoder** | Three branches: frozen VLM (semantics), trainable umT5 (control), frozen CLIP (visual) |
| **Diffusion Transformer** | DiT backbone with Cross-Attention and AdaLN modulation for conditional denoising |

---

## Solving Conditional Image Leakage

**Conditional image leakage** occurs when the denoiser exploits the input image as a shortcut, causing muted motion and color drift.

| Technique | Purpose |
|-----------|---------|
| **Latent Shifting** | Implicitly inject image condition by offsetting latents, avoiding direct concatenation |
| **Fourier Guidance** | Extract high-frequency features to help recover fine details (edges, textures) |

### Dataset Pipeline

1. **Source Collection**: High-quality short videos (5-20s, 720p+)
2. **Keyframe Extraction**: Middle-frame strategy for representative content
3. **Style Transfer**: Apply Step1X-Edit for artistic transformation
4. **Video Synthesis**: Use Wan2.1-I2V-14B for temporal coherence

### Supported Styles (13 Total)

| Category | Styles |
|----------|--------|
| **Animation** | Ghibli, Disney, Chibi, Fairy Tale |
| **Traditional** | Oil Painting, Ink Painting |
| **Digital** | 3D Rendering, Pixel Art, Lego, Vaporwave |
| **Thematic** | Cyberpunk, Gotham Noir |

**Dataset Scale**: ~600,000 styled images (Ghibli & 3D: ~200K each; others: ~20K each)
